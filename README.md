🚀 How to Deploy (Step by Step)
Never deployed a website before? No worries — here's the full guide.
Step 1 — Set up your folder
Create a folder on your computer called `virginia-poppy-nails`
Drop the `index.html` file inside it
Open VS Code → `File` → `Open Folder` → select that folder
---
Step 2 — Install Git (one time only)
Visit https://git-scm.com/downloads and download Git
Install with default settings
Open VS Code's terminal (`Terminal → New Terminal`) and confirm it worked:
```bash
git --version
# Should show something like: git version 2.x.x ✅
```
---
Step 3 — Create a GitHub account & repository
Go to https://github.com and sign up (it's free)
Click + (top right) → New Repository
Name it: `virginia-poppy-nails`
Set visibility to Public
Click Create Repository
---
Step 4 — Push your code to GitHub
In the VS Code terminal, run these one by one:
```bash
git init
git add .
git commit -m "🌸 Launch Poppy Polish website"
git branch -M main
git remote add origin https://github.com/YOUR-USERNAME/virginia-poppy-nails.git
git push -u origin main
```
> 🔁 Replace `YOUR-USERNAME` with your actual GitHub username.
---
Step 5 — Go live with GitHub Pages (free hosting!)
On your GitHub repo, click Settings
In the left sidebar, click Pages
Under Branch, select `main` and folder `/ (root)` → click Save
Wait about 2 minutes ⏳
Your site is live at:
```
https://YOUR-USERNAME.github.io/virginia-poppy-nails
```
🎉 Share that link everywhere — Instagram bio, WhatsApp status, Google Business, everywhere!
---
Step 6 — Updating the website in future
Any time you make changes to `index.html`, just run:
```bash
git add .
git commit -m "Updated website"
git push
```
The live site refreshes within a minute or two. That's it!

💡 Tips & Customisation
Want to add your real Instagram?
Search for `instagram` in the file and drop in your handle link.
Want to add real photos?
Replace any of the SVG gallery blocks with `<img>` tags pointing to your own nail photos.
Want a custom domain? (e.g. `poppypolish.co.ke`)
Buy a `.co.ke` domain from providers like Truehost or Kenya Web Experts (~KES 1,500/yr)
In GitHub → Settings → Pages → Custom Domain → enter your domain
Follow the DNS setup instructions they provide
Want to change the WhatsApp number?
Press `Ctrl + H` in VS Code, search `254718605695`, replace with your new number in international format (254 + number without the 0).
